# Moodprint Android 테스트 전략

## 순수 단위 테스트

- 추천: 1~3개 감정, 에너지 일치, 최근 3회 반복 제어, 사용자에게 노출하는 reason을 검증한다.
- 타이머: 절대 종료 시각, 일시정지, 재개, 종료를 시계와 무관한 상태 테스트로 검증한다.
- 달력: 윤년, 월·연도 경계, 타임존, 42칸 그리드 정렬을 검증한다.

## Room 통합 테스트

- 인메모리 DB에서 같은 resultId 보상이 한 번만 적용되는지 검증한다.
- result, reward, 펫 성장이 하나의 트랜잭션으로 rollback되는지 검증한다.
- 프로세스 재생성 후 활성 mood/session이 다른 기록에 연결되지 않는지 검증한다.

## Compose UI·접근성 테스트

- 최대 글자 크기와 작은 화면에서 모든 핵심 CTA에 스크롤로 접근할 수 있어야 한다.
- TalkBack에서 감정 선택 상태, 잠긴 펫, 기록이 있는 날짜가 색상 없이도 전달되어야 한다.
- 회전, 백그라운드 복귀, 프로세스 재생성 후 타이머와 탐색 상태를 검증한다.
