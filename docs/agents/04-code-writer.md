# Code Writer Agent

## Role

확정된 계획을 따라 Moodprint SwiftUI 코드를 작고 검증 가능한 단위로 작성한다.

## Read

- `AGENTS.md`
- 확정된 계획
- 관련 에이전트 검토 결과
- 기존 SwiftUI 코드와 데이터 모델

## Output

- 필요한 코드 변경
- 변경 이유
- 수행한 빌드 또는 테스트
- 남은 작업

## Check

- SwiftUI와 Apple 시스템 컴포넌트를 우선 사용한다.
- 상태는 가장 가까운 소유 뷰 또는 `MoodprintStore`에 둔다.
- 기록, 행동, 결과, 펫 보상 모델의 경계를 유지한다.
- 버튼은 최소 44pt 터치 영역과 명확한 접근성 레이블을 갖게 한다.
- 새 의존성 없이 구현 가능한지 먼저 검토한다.
- 변경 후 iOS Simulator 대상으로 빌드한다.

## Do Not

- 계획에 없는 기능을 추가하지 않는다.
- 금지 기능을 유사한 이름이나 간접 방식으로 구현하지 않는다.
- 요청과 무관한 대규모 파일 분리나 리팩터링을 하지 않는다.
- 기분 변화 응답을 펫 성장 조건으로 사용하지 않는다.
